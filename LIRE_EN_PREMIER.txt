MYSTERY ESCAPE'S - INSTALLATION CORRIGEE
=======================================

IMPORTANT : NE PAS IMPORTER LE FICHIER ZIP DIRECTEMENT DANS GODOT.

1) Dans l'Explorateur Windows : clic droit sur MysteryEscapesUltimate_CORRIGE.zip
   puis "Extraire tout" dans un NOUVEAU dossier.
2) Ouvrir le dossier extrait : vous devez voir project.godot et les dossiers
   assets, scenes, scripts et data.
3) Double-cliquer sur VERIFIER_INSTALLATION.bat : il doit afficher OK.
4) Ouvrir Godot > Gestionnaire de projets > Importer.
5) Selectionner le fichier project.godot (PAS le ZIP).
6) Ouvrir scenes/main_menu.tscn, passer en vue 2D, puis appuyer sur F5.

Si Godot affiche encore une scene vide, verifier dans le panneau de gauche
que scenes/main_menu.tscn et scripts/app.gd sont bien visibles.

Ce projet est une version de developpement. L'archive et la structure
sont verifiees, mais le projet n'a pas pu etre teste dans Godot ici.
