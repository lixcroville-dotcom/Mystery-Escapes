MYSTERY ESCAPE'S V4 - INSTALLATION RAPIDE

100 DOSSIERS PRINCIPAUX + 10 ENQUETES ENFANT
22 MUSIQUES INSTRUMENTALES (26 MIN 24 S)

1. Extraire le ZIP dans un nouveau dossier Windows.
2. Godot 4.7.2 -> Importer -> project.godot.
3. Dans Godot, ouvrir scenes/main_menu.tscn en 2D puis F5.
4. Tester musique menu/boutique/classement, tutoriel, parametres (glisser le doigt), et mode Enfant.
5. La compilation iOS gratuite est configuree via .github/workflows/ios-ipa.yml.
6. Le projet n'a pas ete execute sur un iPhone dans cet environnement ; le resultat depend du build et des tests sur ton appareil.

SAUVEGARDE : user://mystery_escape_save_v2.json, conservee et sauvegardee dans un fichier .bak.
IDENTIFIANT IOS : com.lixcroville.mysteryescapes, inchange.

Pour mise a jour GitHub, lire INSTALLER_SUR_GITHUB_CMD.txt.
