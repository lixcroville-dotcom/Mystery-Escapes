# Mystery Escapes : compiler un IPA unsigned (Windows + GitHub Actions)

Ce paquet contient UNIQUEMENT la configuration iOS. Il ne contient pas le jeu.

Mettre ces deux fichiers à la racine du dépôt local qui contient `project.godot` :
- `export_presets.cfg`
- `.github/workflows/ios-ipa.yml`

CMD (depuis le dossier git qui contient `project.godot`) :

    git add export_presets.cfg .github/workflows/ios-ipa.yml
    git commit -m "Ajouter build IPA iOS gratuit"
    git push origin main

Sur GitHub : Actions -> Mystery Escapes - IPA iPhone (unsigned) -> Run workflow.
Lorsque tout est vert, ouvrir la run -> Artifacts -> MysteryEscapes-IPA-non-signe.

Notes :
- Compilation GitHub Actions macOS gratuite sous les conditions des dépôts publics.
- Le paramètre `ABCDE12XYZ` est un team ID FICTIF uniquement pour générer un projet Xcode non signé.
- L'IPA doit encore être signé sur Windows (Sideloadly) avec le compte Apple de l'utilisateur.
- Il peut y avoir des erreurs spécifiques à l'export iOS ou à Xcode. Ce fichier n'est pas testé sur runner macOS.
- Ne jamais placer de mot de passe Apple ou de clé privée dans le dépôt public.
- La signature Apple gratuite expire normalement au bout de sept jours.
