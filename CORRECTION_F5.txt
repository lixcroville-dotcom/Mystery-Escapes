MYSTERY ESCAPE’S - CORRECTION F5 (Godot 4.7)

ERREUR CORRIGEE : app.gd utilisait set_theme(which: int),
fonction entrant en conflit avec CanvasItem.set_theme(Theme).
La fonction du jeu s’appelle maintenant select_visual_theme.

INSTALLATION :
1) Fermez Godot.
2) Cliquez droit sur ce ZIP puis « Extraire tout ».
3) Dans le gestionnaire Godot, utilisez « Importer » et pointez vers project.godot
   dans le NOUVEAU dossier extrait, et non vers le fichier ZIP.
4) Ouvrez scenes/main_menu.tscn puis F5.

SI VOUS AVEZ DEJA LE PROJET :
Copiez uniquement scripts/app.gd depuis ce ZIP dans le dossier scripts
de votre projet, en remplaçant le fichier existant.
Redémarrez Godot, puis F5.

Godot n’étant pas installé dans l’environnement de génération,
aucun test d’exécution Godot n’a pu être effectué.
